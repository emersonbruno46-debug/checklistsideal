# Ideal Checklist's

**Teste. Valide. Entregue.**

Sistema completo para transformar documentos de QA e checklists em auditorias digitais interativas com estrutura profissional: **SEÇÃO ➔ CENÁRIO ➔ PASSOS ➔ VALIDAÇÕES**.

## Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Zod (Validação de Schema QA)
- Supabase (Auth, Database, Storage)
- Lucide Icons
- jsPDF & html2canvas (Exportação em PDF)

## Estrutura de QA
- **Seção**: Módulo ou agrupamento principal
- **Cenário de Teste**: Funcionalidade testada
- **Passos**: Instruções de execução para o testador
- **Validações (Assertions)**: Critérios de sucesso esperados

## Como rodar localmente
```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000)
